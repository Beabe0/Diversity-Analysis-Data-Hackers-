# Diversity-Analysis-Data-Hackers-
As a final project for the PrograMaria course "My First Steps in Python," I conducted a diversity analysis based on the 2022 State of Data survey (by Data Hackers). I analyzed the data to identify patterns of inequality across several dimensions, including gender representation, educational background, salary disparities, seniority levels, and regional differences.
For missing values ​​in the SALARY column, I opted to use the overall median of the variable, calculated via dados['SALARIO'].median(). I chose the median because the salary distribution may be skewed and influenced by very high values; in this context, it provides a better representation of the center of the data than the mean. Subsequently, I filled the null values ​​using fillna by applying the assignment via loc.
I also analyzed extreme values. I calculated an upper limit based on the mean salary plus three standard deviations and examined the salary ranges in which these values ​​appeared. Rather than simply deleting these records, I replaced some outliers with the mean values ​​calculated for their respective salary ranges, aiming to maintain consistency with the context of the variable.
For gender, I filled null values ​​with "Prefer not to say"; for age, I used the mean corresponding to the specific age group, whenever that information was available.
